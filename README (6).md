# Халдун

Teen Хуралдай 2026-ийн төсөл. Сурагчид нойр, өглөөний цай, дасгал хөдөлгөөн, анхаарал, сэтгэл санаагаа өдөр бүр 2 минутад тэмдэглэдэг вэб апп. (Хуучнаар «Жалайр» гэж нэрлэгддэг байсан.)

## Үндсэн боломжууд
- **Өглөө, оройн богино асуултууд.** Хариулт бүрийн дараа хувийн дүгнэлт гарна.
- **Сэтгэл санааны 20 тайлбар.** Өглөөний картанд «Яагаад ийм мэдрэгддэг вэ?», «Одоо би юу хийж болох вэ?», «Хэзээ тусламж хүсэх вэ?» гэсэн хэсгүүд байна. Онош тавихгүй. Хэцүү үед 108 (Хүүхдийн тусламжийн утас), 1800-2000 (Сэтгэцийн эрүүл мэндийн утас) дугаарыг санал болгоно.
- **Би › Сэтгэл санаа.** Ажиглагдсан мэдрэмжүүд, давтагдсан шалтгаанууд, тэдгээрт тохирох зөвлөмж харагдана.
- **Хоол, дасгал.**
  - Өглөөний 20 хоолны жор.
  - Зохистой хооллолтын гэр.
  - 1, 5, 10 минутын дасгал.
  - Шагайн сорил.
  - 60 секундын анхаарлын тест.
- **Гал.** Өдөр бүр бөглөхөд гал асаж, дараалсан өдрүүд календарьт нэмэгдэнэ.
- **10 дүр.**
  - Асуулга бөглөөд өөртөө хамгийн ойр дүрээ олно.
  - Дүр дэлгэцийн буланд байж урам өгөх үг хэлнэ. Чирж байрлалыг нь сольж болно.
  - Дүр дээрээ удаан дарвал нуух, эсвэл өөрөө ярихгүй болгох сонголт гарна.
- **13-р зууны аялал.** 2D эсвэл 3D-ээр үзэх түүх, 4 бүлэгтэй: Нартай хамт сэрэх, Морь ба сур харваа, Шагайн наадам, Нар жаргахад.
- **«Миний нутаг».**
  - Гал 15 хоног дараалан асаахад нээгддэг 3D тоглоом.
  - Гэрээ өөрөө барина. Мал, айраг, ааруул, шагай, сур харваатай. Өдөр, шөнө солигдоно.
- **AI чат.** Claude-ийн линкээр нээгээд зөвшөөрөл өгвөл Claude хариулна. Бусад үед аппын энгийн хариулагч ажиллана.
- **Утсанд суулгах (PWA).** Нүүр дэлгэцэд нэмж, апп шиг нээж болно.

## Файлын бүтэц
| Файл / хавтас | Юу вэ |
|---|---|
| `index.html` | Үндсэн апп (бүх HTML, CSS, JS нэг файлд) |
| `ch1/` | 13-р зууны аяллын 3D загвар, бүтэц (texture) |
| `nutag/` | «Миний нутаг» 3D тоглоом |
| `sw.js` | Service worker: интернэт тасарсан үед нүүр хуудсыг нээнэ |
| `manifest.webmanifest`, `icon-*.png` | Утсанд суулгах тохиргоо ба icon-ууд |

3D хэсэг нь аппын өөрийн WebGL кодоор зурагддаг, нэмэлт сан татахгүй. Удаан утсан дээр чанар нь өөрөө буурна. 3D загваруудын эх сурвалж, лицензийг апп доторх Тохиргоо › «3D загваруудын эх сурвалж» хэсгээс харна.

## Өгөгдөл ба нууцлал
- Үндсэндээ мэдээлэл зөвхөн хэрэглэгчийн өөрийн хөтөч дээр хадгалагдана.
- Имэйлээр бүртгүүлж нэвтрэх (Supabase) боломж одоохондоо хаалттай. Зөвхөн `?supa=1` холбоосоор нээгдэнэ.
  - Supabase-д хэрэглэгч бүр зөвхөн өөрийн мөрийг унших, бичих эрхтэй (Row Level Security).
  - Кодонд зөвхөн нийтэд нээлттэй (publishable) түлхүүр байгаа. `service_role` түлхүүр, SMTP нууц үг зэрэг нууц мэдээллийг энэ repo-д **хэзээ ч бүү оруул**.
- Хувийн тэмдэглэл, сэтгэл зүйн хариултыг багийнханд харуулахгүй.
